# P21：残差灵敏度校准与模型规模对照

针对 [P20 完整结果](restoration-head-study.md)中约 87% 更新触发梯度裁剪、
固定训练误差高于初始化的问题，本轮先校准优化尺度，再比较容量。
不能把相同学习率下优化困难的模型当作已测出的容量上限。

## 改动与固定对照

把残差坐标从 `2 * tanh(z)` 改为 `2 * tanh(z / 64)`。
这是缩小零点附近的输出导数，不是把最终幅度上限乘以 1/64：
两者最大坐标范围仍为 ±2，完全缺失频带仍能生成能量。
`1/64` 是在本轮训练之前，根据 P20 初始梯度约放大 88–89 倍的诊断固定的校准值；
没有根据本轮开发复核结果搜索。输出放大风险是否得到控制仍由后续训练决定。

因果 TCN、上下文更新、DSP、主 loss、clean-complex 辅助目标和权重均沿用 P20。
不增加未来帧或输出缓冲。checkpoint 显式保存 width、head 和 slope，导出按配置恢复，
旧 P20 checkpoint 使用原有默认值。

| 校准配置 | width | 参数 | 残差斜率 | Adam 学习率 |
| --- | ---: | ---: | ---: | ---: |
| anchored 控制 | 144 | 807,398 | 原头 | 1e-4 |
| unscaled 控制 | 144 | 824,658 | 1 | 1e-4 |
| lowrate 控制 | 144 | 824,658 | 1 | 1e-4 / 64 |
| scaled96 | 96 | 430,050 | 1/64 | 1e-4 |
| scaled144 | 144 | 824,658 | 1/64 | 1e-4 |
| scaled224 | 224 | 1,748,578 | 1/64 | 1e-4 |

最大的复数模型约为现有 144-width 的 2.12 倍参数，仍低于 2M。
相同 width 和种子校验共享主干初始化哈希；不同 width 的张量形状不同，不声称初始化
权重逐元素相同。lowrate 与 scaled144 分离学习率调整和输出参数化调整的影响。

## 两阶段执行

全部配置及后续端点已在开始训练前登记。沿用 P20 的 253 个音乐录音、8 个语音录音、
2,088 个裁剪和种子 `20261012 / 20261013` 的相同抽样顺序。每步 4 音乐 + 1 语音，
每个素材同时有 paired 与 identity，风险各半；这是继承的诊断抽样比例，不改变最终
产品训练的语音比例约定。Adam 无 weight decay、梯度范数裁剪 5。

**校准阶段：**六配置 × 两种子 × 512 步，共 6,144 更新。
同时评分共同 320 裁剪与完整 2,088 裁剪训练池，观察恢复、原音损伤、combined loss、
梯度裁剪比例和各规模导出成本；不评分 development，也不挑选最优种子/端点。

预先固定的继续条件是三种 scaled 规模、两个种子全部满足：

- 共同训练集 main、paired、combined 均优于初始化，完整训练池 main/paired 也下降；
- 共同与完整训练池的 identity 不差于相同种子的 anchored 控制（数值容差 1e-6）；
- 裁剪比例不超过 25%，作为优化过程诊断上限，不作为音质验收标准；
- 参数不超过 2M、单图小于 8 MiB，单线程双声道诊断路径 p99 小于 48 kHz 单 hop 时长。

任何一个规模/种子失败，流水线写出 `calibration_rejected` 并停止，不自动进入长训练，
也不把通过的子集包装成完整容量结论。该门槛是训练过程筛查，不是发布或听感合格。

**后续完整阶段：**仅在上述筛查全部通过时自动执行。
anchored144 + scaled96/144/224，两个种子，各从共同恒等起点**重新训练** 8,192 步，
共 65,536 更新；固定 2,048 / 8,192 端点。不从校准阶段挑选或迁移较好权重。
全部训练完成、冻结 16 个端点哈希后，再评分 89 个 development 配对片段和
40 个 shifted 片段；初始控制加 16 个端点，共 3,026 次 Rust 角色回放。

比较每个规模与 anchored、96→144、144→224 的同预算结果。按 clip 和 recording
分别聚合音乐/语音，保留逐片段退化与最坏案例。数据是复用的开发复核，不能证明无过拟合。
恢复主误差、实际 DSP 高频谱形和瞬态须优于匹配控制和初始 DSP，且原音保真、能量和
低频不恶化；仍不能代替新录音独立评估、盲听及连续设备验收。

本轮各控制的匹配结果。单元测试另外验证初始化 Jacobian 按 1/64 缩小、恒等输出不变、
可表达输出范围保留、静音梯度有限及旧新 checkpoint 恢复。全部 Python 测试 492 passed，
Ruff 检查通过。
