# P17：一致性训练的学习率续训对照

## 运行前协议

P16 第二种子从 256 到 2,048 步在完整训练位置库上的主项、辅助项和组合目标均退步。
本轮只检验较小更新能否缓解这一优化问题，不直接扩容、不改变 loss，也不延长原长训。

- 起点：P16 consistency 两种子 20261012 / 20261013 的固定 `step-256.pth`。
- 完整恢复模型、Adam 一阶/二阶动量、计数和随机状态；只覆盖学习率。
- 每种子比较 lr=1e-3 / 1e-4，各走 256 步，到总步数 512；共四组。
- 继续原 `crop_draws[256:512]`，辅助系数保持 0.1365237430457469。
- 保持 40 录音 × 8 位置、4 音乐 + 1 语音及对应 identity、原模型、loss、clip=5。
  这是诊断抽样比例，不改变正式训练库的语音混入规则。
- 在总步数 256 / 320 / 384 / 448 / 512 评估全部 320 个训练位置；每次位置权重相同。
- 记录配对恢复、identity、原主项、辅助项及组合目标，保留逐位置主项和逐步更新日志。
- 原学习率分支在 320 / 384 / 448 / 512 的更新前主项和辅助项须复现原 P16 日志，
  绝对容差 1e-7；两个共同起点的完整训练评分须复现旧报告，容差 1e-6。
- checkpoint 哈希在评分前登记。所有固定时点评分都报告，不挑最好点或种子。
- 使用既定五个训练 anchor 配对及其 identity，在两个共同起点和四个终点做共 60 次
  Rust DSP 回放。这不等于新候选 ONNX 的流式推理验证。
- 不读取开发音频评分，不使用新的留出录音；不宣称泛化通过，不替换默认权重。

## 判读规则

使用 1e-6 作为数值一致性容差，不作为可感知改善阈值。支持继续研究较小更新，需要
两个种子在固定终点的主项和组合目标均低于各自起点及原学习率分支，且配对恢复和
identity 均不比起点更差。另报告中间固定时点的最坏误差和超过起点的次数，不能
仅凭终点更好称为全过程稳定，也不要求随机优化每一步严格单调。

如果较小更新也不能改善完整训练库，继续查实际输出更新尺度及目标耦合；
如果短程改善，只能说明该续训窗口支持优化方向，仍需另行登记更长训练和跨录音复核。
本轮不能证明 P16 后期失败完全由学习率引起，也不能证明容量充足或学习率已经最优。

## 结果：较小更新通过短程优化判定

完整训练位置库上的共同主误差（不是开发集、不是加入辅助项后的总分）：

| 种子 | 起点 256 | 原 lr=1e-3，512 步 | 小 lr=1e-4，512 步 | 小 lr 相对起点 |
| --- | ---: | ---: | ---: | ---: |
| 20261012 | 0.290827 | 0.287360 | 0.279703 | -3.82% |
| 20261013 | 0.289273 | 0.291007 | 0.279112 | -3.51% |

小学习率相对原学习率终点分别低 2.66% / 4.09%。两个种子均通过登记的四项检查，
包括组合目标改善以及配对恢复、identity 不退步。
原学习率分支的八个更新前日志检查全部通过；共同起点评分亦复现 P16。

小学习率终点分项：

| 指标 | 20261012：起点 → 终点 | 20261013：起点 → 终点 |
| --- | ---: | ---: |
| 配对恢复 | 0.560540 → 0.554782 | 0.556942 → 0.553433 |
| identity 损伤 | 0.021114 → 0.004623 | 0.021604 → 0.004791 |
| 辅助项 | 0.116055 → 0.105803 | 0.111606 → 0.105066 |
| 组合目标 | 0.306671 → 0.294147 | 0.304510 → 0.293456 |

配对恢复改善 1.03% / 0.63%，identity 损伤降低 78.10% / 77.83%。
按主项的等权分解，总下降的 74.12% / 82.73% 来自 identity 损伤减少。
因此这是优化与保真改善证据，不是大幅补回缺失高频的证据。

四个中间/终点检查中，小学习率两种子的主误差均未超过各自起点；原学习率分别
有 1/4、3/4 次超过起点。第二种子的原学习率在第 384 步升到 0.348863，
小学习率同点为 0.279661。
但小学习率第二种子第 320 步的配对恢复、辅助项仍曾高于起点，384 → 448 步
主误差也略回升。只能说登记检查点上的主目标反弹减少，不能称所有步骤和指标单调稳定。

## 原生 DSP 与证据边界

60 次回放的代理/Rust 最大绝对差为 **2.384186e-7**。
固定五对训练片段（4 音乐 + 1 语音）的配对高频指标，相对各自 256 步起点：

| 小学习率终点变化，负数更好 | 20261012 | 20261013 |
| --- | ---: | ---: |
| 高频谱收敛误差 | +0.000467 | -0.002911 |
| 高频瞬态误差 | +0.001526 | -0.004503 |
| 高频能量绝对误差，dB | +0.022896 | +0.245379 |

谱形与瞬态方向不一致，能量误差均略上升；不能用全训练库平均 loss 代替它们。
同一固定子集的 identity 高频谱形/瞬态/能量误差均改善，进一步支持主要收益是减少破坏。
这些少量训练片段不代表跨录音音乐质量，也不代表立体声、实际设备和盲听验收。

本轮没有开发集重评、独立测试、盲听或候选 ONNX 导出；没有修改运行时图和 DSP，
没有替换默认权重。不能把这组短程结果解释为已超过初始恒等基线或解决 P16 所有后期问题。

下一步适合另行登记固定预算的双种子低学习率续训，继续保留完整训练库检查，
并在冻结终点后复核跨录音音乐与原生高频细节指标；不按开发分数挑点。
若只是 identity 继续变好而配对高频恢复没有一致改善，就不追加相同长训，
转向音乐覆盖和输出表示的可表达性对照。当前结果不支持直接扩大模型。
