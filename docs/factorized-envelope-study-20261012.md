# P6：频带能量包络与带内谱形分工

承接 [P5](envelope-study-20261012.md) 的参考干预证据，正式训练前登记如下协议。
本轮检验结构与目标的作用，仍是原始幅度研究，不跳过相位、DSP、盲听和实时发布门槛。

## 对照设计

三组各两个种子 `20261012 / 20261013`，每组 **2048 更新、batch 4**，从头训练。

| 组别 | 输出结构 | 训练目标 |
| --- | --- | --- |
| direct_legacy | P5 直接幅度残差头 | P5 压缩幅度＋时间差分 |
| direct_factored_loss | 相同直接幅度头 | 分项能量/谱形目标 |
| factorized | 逐帧五频带 RMS 头＋129-bin 带内形状头 | 相同分项目标 |

三组共用 P5 的 past-only 1024/2048 点输入、每四 hop 更新、width=144 TCN，以及在线输入带宽条件。
**训练与所有指标都排除前 80 hop**，覆盖长窗与 TCN 的完整组合历史；不读取未来。
相同种子共享所有公共骨干初始张量，最后的幅度残差层统一置零，从近似恒等函数开始。
factorized 仅增加一个 288→5 能量头（1445 参数），不靠明显扩容比较。

每带形状由正幅度种子归一化 RMS，独立能量头预测相对输入该带的对数 RMS 修正。
输入相对频带 RMS 保留约 1e-8 的微小下界，允许完全缺失的频带生成；
输出相对全谱 RMS 的对数限于 [-30, 2]。这不是 oracle：推理中不存在 clean 参考。
给某带改变能量不能改变其归一化形状，改变形状不能改变该带预测能量；分别验证这两个性质。
极弱输入下仅保留数值地板，不宣称数学上的严格零输出；验证其有限值和梯度。

## 目标、选模与数据

频带仍为 0–4、4–8、8–12、12–16、16–Nyquist kHz；低带权重 0.25，高带各 1，除以 4.25。
令参考监督区域全谱 RMS 的 1e-4（最低 1e-7 DFT 幅度）为 floor：

- 能量项：每帧每带平滑 RMS 的对数差绝对值。
- 谱形项：各自平滑 RMS 归一化的逐 bin 幅度绝对差；以参考带功率相对 floor 的置信度加权。
- 动态项：预测与参考的**有符号**对数频带 RMS 时间差分之差，保留真实瞬态。
- 保留 P5 压缩幅度项。共同总分 = 能量 + 0.5×谱形 + 0.25×动态 + 0.25×P5幅度。

floor 用于平滑/归一化，不改变目标参考。新旧 loss 总值不能直接比较。
每 512 步用**相同分项目标**对三组评分：音乐/语音 253/254 与 1/254，再混合 paired 87.5%、identity 12.5%。
近似恒等的初始第 0 步也可选为最佳，避免强行把退化训练结果称作候选。
AdamW lr=1e-4，余弦衰减至 0.1 倍，weight decay=1e-4，梯度裁剪 5。

沿用核验过的无损来源与作品/源校验和隔离，不加载 P5 权重。
每种子使用 `seed+40000` 新生成 8192 个固定抽样；同种子三组完全相同，12.5% 替换为原生恒等输入。
所有组都保留单声道、语音及弱高频录音，不按失败样本删数据或改阈值。
开发集和训练探针沿用既有定义，不称独立测试，不在本轮读取历史 test 评分。

## 预先规定的判读

分别比较 direct_factored_loss 对 direct_legacy（目标作用）、factorized 对 direct_factored_loss（结构作用）。
按录音配对 bootstrap，两个种子分别报告；主证据为高频 SC 与能量误差共同改善，
并审查 flux、原压缩输入、原生恒等、低频和语音。总 loss 降低不能单独晋级。
若两种子不一致、区间跨零，保留不确定性；若只有目标组改善，不将收益归功于新结构。
不使用微小指标波动推断可闻质量，不把维持压缩输入或初始第 0 步胜出当作恢复成功。
固定 factorized 权重后替换历史特征作诊断，不重新选择 checkpoint。

模型、loss 测试覆盖参考最优、弱能量/静音梯度、有限差分、MPS/CPU、因果与分块/声道隔离；
通用训练器新增中断恢复一致性和产物完整性检查。
规模仍限制 <=2M 参数、诊断 ONNX <8 MiB。CPU逐 hop 成本与完整音频延迟、发布稳定性分开报告。

为避免停留在原始幅度指标，选模冻结后另做实际 Rust DSP 诊断（不参与选模）：
每种子使用对应冻结 P3 control 的相位，比较 P3 原输出、恒等 DSP、三组幅度替换，以及
factorized 配输入相位。全部使用相同前 80 hop 原输入预测、Model gain、smooth-knee，
统一评分裁剪 `(80+9)*128 : 32768-128`。复用全部开发片段，分别报告音乐/语音、
清单截止频率的 HF 指标和固定 4 kHz 以上指标，同时验证 Rust 输出与代理误差 <=2e-5。
这是离线预测特征通过真实合成链；不等于新模型已经接入流式运行，也不构成盲听。

## 训练前边界修正

首批 `892e618` 已中止，全部结果排除在最终对照之外。补充完整缺失频带探针发现：
初版 -18 下限高于输入 1e-8 种子对应的对数值，能量梯度被截断；零幅度处的对称平方种子
也会令谱形头梯度为零。修正为 -30 下限，并给形状种子增加微小正偏移，
加入严格零输入和实际 1e-10 特征地板两类回归，要求能量与谱形头均有正确方向/非零有限梯度。
修正批次使用新目录、冻结源码和完整六组重跑；抽样种子、训练预算、loss 与选模规则不变。
仅复用以源音频/抽样/检测器哈希寻址的输入特征缓存，不复用旧权重或旧评测结论。

## 六组修正版已完成

正式来源 `186301b`，目录 `data/runs/factor-p6b-20261012/study/`。
两个种子各 8192 抽样，其中 1024 个恒等控制；全部六组完成 2048 更新，且都选中第 2048 步。
最佳步骤均位于预算边界，因此尚未证明收敛，也不能排除更长训练的收益；本轮架构结论只限于这个匹配预算。
以下为 33 个开发音乐片段、26 个录音的片段等权均值，固定频带、80 hop 排除区。
“共同目标”是 paired 音乐分项总分，不是加入语音/恒等后的选模加权分数。

| 组别 / 种子 | 共同目标 ↓ | 高频 SC ↓ | 高频 flux ↓ | 高频能量误差 dB ↓ |
| --- | ---: | ---: | ---: | ---: |
| 压缩输入 | 1.12013 | 0.54790 | 0.71550 | 8.83169 |
| direct_legacy / 12 | 0.85916 | 2.11832 | 1.37725 | 5.06870 |
| direct_factored_loss / 12 | 0.85139 | 3.48862 | 1.88541 | 5.01535 |
| factorized / 12 | 1.04358 | 1.06465 | 1.01669 | 7.54628 |
| direct_legacy / 13 | 0.86796 | 2.16476 | 1.45297 | 5.17911 |
| direct_factored_loss / 13 | 0.84235 | 3.71767 | 1.92805 | 4.87881 |
| factorized / 13 | 1.04413 | 0.70118 | 0.79353 | 7.66464 |

结论是**存在结构作用，但尚未建立整体恢复收益**：

- 仅换 loss：按录音配对，高频 SC 增加 **+1.4285 / +1.7056**，flux 增加
  **+0.5483 / +0.5030**，两种子的 95% bootstrap 区间均在零以上。能量误差小幅减少的区间
  均跨零。总分或平均能量更好不能覆盖谱形/瞬态退步。
- 同 loss 换成双分支：SC 平均差 **-2.6396 / -3.3452**，flux **-0.9859 / -1.2840**，
  能量误差 **+2.7493 / +3.0601 dB**。第一种子 SC/flux 区间跨零，第二种子才均低于零；
  两个能量误差区间也都跨零。因此不能把大幅片段均值变化等同于跨录音稳定优势。
- 对压缩输入，factorized 能量误差配对差 **-1.4859 / -1.3226 dB**，区间均低于零；
  但 SC 仍增加 **+0.4930 / +0.1290**，区间均高于零。仍未满足主要恢复指标共同改善。

原生恒等音乐的 factorized 高频能量误差仍为 **1.755 / 1.312 dB**，说明没有完全避免
不必要的修改。语音的 SC 为 **0.388 / 0.341**、能量误差 **0.975 / 0.773 dB**，单独保存，
不以音乐均值代替语音结论。训练音乐探针共同目标为 **0.9524 / 0.9614**，开发为
**1.0436 / 1.0441**；探针与开发内容不同，这个差值不能直接当作过拟合量。
本轮使用复用开发集，未增加独立测试或盲听证据。

### 同频带、同时间窗复核

动态截止频率 HF 与固定频带均值反映不同区域。为排除口径混淆，对上述相同 1068 个组合
补做同窗复核，另存 `dsp-aligned-*`，不覆盖首批登记，不当作新增独立样本。
原始幅度和实际输出重分析都使用 256 FFT / 128 hop、同一原点、同一参考、五个固定频带；
只保留完整落入共同评分区的窗口（帧 89:254）。输出已含合成延迟，不再额外左补零。
加入恒等时间轴回归，要求同一信号的 SC、flux 和能量误差近零。

| 同 loss 路径 / 种子 | 原始 SC | 输出 SC | 原始 flux | 输出 flux | 原始能量误差 dB | 输出能量误差 dB |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 直接头 / 12 | 3.4923 | 2.8985 | 1.8895 | 1.8574 | 5.0159 | 5.0599 |
| 双分支 / 12 | 1.0731 | 0.9477 | 1.0212 | 0.9675 | 7.5603 | 6.8937 |
| 直接头 / 13 | 3.7199 | 2.9005 | 1.9352 | 1.9395 | 4.8848 | 5.1041 |
| 双分支 / 13 | 0.7046 | 0.6562 | 0.7943 | 0.7905 | 7.6809 | 6.8182 |

两路均配相同 P3 相位。相同口径下，双分支的平均 SC/flux 优势在 DSP 后仍存在，
能量误差的代价也仍存在。按录音配对，输出 SC 差 **-2.0940 / -2.4900**，
95% 区间 **[-5.0348, 0.0533] / [-5.9363, -0.0735]**；输出能量误差差
**+1.9935 / +1.9197 dB**，区间均跨零。因此不能将不同口径下的“反转”直接归因于相位或 DSP。

逐带输出进一步定位：16 kHz 以上，直接头的 SC 为 **8.0881 / 8.2311**，双分支为
**2.4906 / 1.3531**；对应能量误差分别为 **11.1106 / 11.2320 dB** 与
**16.5793 / 17.0778 dB**。双分支的该带平均有符号能量偏差为 **-7.6078 / -12.6903 dB**，
但绝对误差明显更大，表明样本间仍混有补不足与补过量，不能靠统一增加增益修复。
这些是开发集事后诊断，不是新晋级门槛。

## 判定与后续突破口

本轮未达到整体恢复目标，也未证明模型容量不足、基线过拟合或单纯 DSP 错误。
默认权重保持不变，优先查清当前折衷，再决定是否做匹配预算的延长训练。

后续先检验两个可区分的假设，再投入完整训练：

1. **缺失带的能量参数化是否限制学习。** 当前以输入该带 RMS 为锚点预测对数修正，
   严重裁切时需要跨越很大动态范围。比较显式输入对数频带能量，以及不依赖缺失带
   输入能量的绝对包络预测；以相同形状头、loss、预算隔离结构作用。此处仍是假设，
   不能由本轮负偏差直接断言已经确认。
2. **能量与可合成细节能否共同改善。** 固定同频带、同窗口评估，区分保留带与受损带，
   同时检查原始幅度、实际合成和自然弱高频录音。再用匹配对照测试合成后的谱形/瞬态
   监督，必要时联合相位；不把动态 HF 和固定频带的差异误判成 DSP 破坏了全部收益。

后续规则应在新训练前登记；继续保留两个种子、录音级区间、恒等/语音控制和实时预算。
独立测试、盲听与完整流式稳定性仍是最终采用的必要证据。

最终核验：六组最佳检查点与评测哈希全部一致；两个种子各 8192 抽样/1024 恒等且摘要一致；
85 个冻结源码文件通过哈希核对，当前模型/loss/正式训练器与登记源码相同。
