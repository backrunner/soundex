## 生成分支

P23 的残差单位为 `global_rms * sqrt(local_power + 1)`；即使整个高频带很弱，
全频 RMS 仍作为生成单位。P24 新分支从同一个因果编码器的 latent 预测五个
`softplus` 非负预算，在 2 / 6 / 10 / 14 / 20 kHz 中心间做连续线性插值，边缘延续。
新单位为 `global_rms * sqrt(local_power + budget(frequency)^2)`。

预算初始值为 1，保留原方案的初始输出与残差尺度；主干初始化逐张量核查。
预算没有硬上限，也不乘以被裁掉频带的输入能量，所以仍可重建完全缺失的高频。
这是可学习的生成尺度，不是校准后的置信概率，也不是严格输出能量上限；局部项仍
允许修改输入已有频率。持续平稳和真实恢复收益必须由后续验证确认。

训练时用原始 clean complex spectrum 与 input 的差，计算各带每帧 residual RMS / input
global RMS 作为教师；identity 教师为零。对预测和教师的 `log1p` 用 Smooth L1，权重
固定 0.1。该权重未通过开发集搜索。教师只进入训练监督，forward 不接收目标、曲目
ID 或 identity 标签。前 80 帧只预热状态，后续 9 帧也不计入预算监督。
budget 因子包含分支与辅助监督，不能把效果细分归因于其中某一个而不做追加消融。

## 新目标与共同评价

balanced/joint 的频带幅度、参考变化误差分母使用
`reference_band_power + reference_global_power + 1e-14`；频带权重仍为低频 0.25、
其余各 1，再除以 4.25，变化误差系数仍为 0.25。
这将弱频带误差联系到整段参考信号的尺度，不设针对反例的 dB 门槛。
它改变了弱带与强带的优化取舍，是否削弱细节恢复需要对照结果回答。

主目标保留 0.25 倍信号相对波形误差，额外加 0.25 倍全幅 PCM 平滑 RMS 误差。
clean-complex consistency 辅助项也加入全频参考功率稳定分母，避免主目标改动后
旧辅助项仍被同一极弱带支配；辅助权重沿用 `0.1365237430457469`。
paired 仍对原始无损参考，identity 仍对恒等模型经过真实 DSP 的输出。
安全限幅对原始参考的误差继续单独报告，不能通过限幅 clean 来隐藏。

所有组统一保留 P23 原始相对评分，并加上共同 balanced proxy 和绝对 PCM 评价。
不同组自身的优化总分不能直接比较为质量改善。复核包括：

- 89 个 development 与 40 个 shifted 配对片段；均为已用过的开发复核，不称独立测试。
- 原有 4,450 个实际 Rust DSP 角色回放，保留 raw model 与 DSP 后的谱形、能量、
  瞬态、低频指标，以及恒等模型 + DSP 控制。
- 新增全部 development 的绝对 PCM 回放：校准的 RMS/dBFS、峰值、逐带误差、
  相对整段参考 RMS；分别对原始 clean 和恒等 DSP，并列未处理压缩输入对 clean。
  不把未归一化 FFT 功率称作 PCM dBFS。shifted 的新增 PCM 指标注明为 DSP 代理。
- 音乐/语音、paired/identity 分开；保留全部行，RMS 用线性单位统计 clip / recording
  均值、p95 与最大值，不通过平均 dB 改变排序。旧相对分数单独保留，不能自动决定发布。
- 每个端点进行非零 ONNX 状态一致性、mono/stereo、44.1/48 kHz、静音/reset 检查，
  单线程 CPU ORT + 因果 FFT 前端 10,000 hop 计时及独立进程 RSS。

不预设新的“不可闻”阈值，也没有自动提升正式权重的路径。真实恢复、听感、全链路
实时成本和独立录音泛化是分别需要取得的证据。诊断计时不含完整 Rust worker/DSP，
不能单凭它宣布满足模型 + DSP <5 ms；固定 256 帧缓冲和 2.667 ms hop deadline 仍保留。
原始素材、配对数据、报告和实验权重继续留在忽略目录，授权来源与正式协议不变。
