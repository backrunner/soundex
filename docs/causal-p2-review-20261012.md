# P2 首种子复核：有进展，尚未全面超过旧权重

2026-10-12，中期检查。[训练方案](causal-training-20261012.md)的第一种子
20261012 三组均完成 4096 步、导出及真实 Rust 评分；第二种子仍在运行。
下面冻结第一种子的结果，不将它冒称两种子结论。默认权重未更换。

后续更新：P2 六组现已完成，见[完整状态](causal-training-20261012.md)。
[基线与 DSP 归因复核](baseline-generalization-20261012.md)进一步发现限幅器也会

## 训练目标与预算

| 主干 | 最佳验证步 | 统一验证 loss | 参数量 | ONNX MiB |
| --- | ---: | ---: | ---: | ---: |
| 同预算旧主干 | 4096 | 2.662400 | 905,734 | 3.550 |
| GRU | 2048 | 2.485908 | 643,458 | 2.471 |
| TCN | 4096 | 2.462378 | 639,906 | 2.479 |

GRU / TCN 的同目标 loss 分别降低 6.63% / 7.51%。GRU 4096 步为 2.4883，
比 2048 步略差，不能据此建议盲目延长训练。TCN 2048→4096 为 2.4769→2.4624，
后半程改善较小。两者体积较小，但训练耗时受首次缓存构建和 I/O 顺序影响，
不能将记录的整组训练秒数当成推理性能比较。

Loss 的改善也须拆开看：音乐 raw-low-complex 从旧主干的 1.0004 降到
GRU 0.00122 / TCN 0.00149。这项权重为 0.1，对新旧音乐总 loss 差的贡献
约 56% / 50%。它有助于原始模型保持低频，但运行时本来就会融合观测低频，
所以总 loss 的全部差值不能等同于输出音质增益。

## 同片段实际 Rust 对照

固定原 89 条开发验证片段，音乐 33 条 / 26 个录音，语音 56 条 / 54 个录音。
原生 44.1/48 kHz，32768 样本中心裁剪，共同稳态区间为 `[72*128,32768-256)`。
下面均为音乐片段等权均值；全片指标另保留在 JSON，不能外推为完整曲目效果。
旧权重、两种 gain 策略和纯 DSP 本轮重新处理同一批输入，未拼用不同窗口的旧报告。

| 路径 | 高频谱形误差 ↓ | 高频瞬态误差 ↓ | 高频能量误差 dB ↓ | SI-SDR dB ↑ |
| --- | ---: | ---: | ---: | ---: |
| 压缩输入 | 0.69958 | 0.82139 | 7.49576 | 27.77139 |
| 原 shape-small / MatchEdge | 0.80451 | 1.27979 | 4.20721 | 26.75789 |
| 原 shape-small / Model gain | 0.77570 | 1.15518 | 6.00342 | 26.93062 |
| P2 旧主干 / Model gain | 1.38157 | 1.41816 | 7.30113 | 26.99665 |
| P2 GRU / Model gain | 1.11588 | 1.22104 | 6.24508 | 27.35952 |
| P2 TCN / Model gain | 1.15316 | 1.20281 | 5.97236 | 27.39247 |
| 纯 DSP spectral | 2.07465 | 2.65664 | 6.73168 | 27.49107 |

谱形误差为高频 spectral convergence，瞬态误差为参考正向 spectral flux 的归一化误差。
新主干优于同预算重训的旧主干；与原有权重相比，TCN 的 SI-SDR 更好，但高频谱形
均值和能量误差不全面胜出。相对压缩输入，两种新主干的音乐 SI-SDR 均值仍下降
约 0.41 / 0.38 dB。新主干 24/33、25/33 音乐片段的谱形误差低于输入，但少数反例
会明显影响均值；不删除这些反例，也不使用“大部分片段改善”代替全面验收。

### 按录音重算统计

发现训练入口 `actual_score` 没有传 `cluster_field`，自动报告实际是 row bootstrap，
与此前文档的录音聚类说明不一致。本次从原始逐行指标重算 **track_id 聚类、4000 次**
bootstrap，配对差值保持录音内所有编码/声道角色一起抽样。固定片段均值不变。
正在运行的训练源码保持冻结，不中途改变登记的实验；新统计写入独立 `*-clustered.json`

## 反例与目标函数缺口

最差的两个音乐片段来自同一首 `Ballad Of Ishmael` 的 AAC192 / Vorbis q3 版本。
原始目标在相应高频区域的能量已经极低，压缩输入几乎未改变它，模型却继续补高频。
使用相同稳态窗口，按单边 Parseval 与 Hann 窗功率校正计算的高频 RMS：

| 片段 | 无损参考 dBFS | 压缩输入 dBFS | P2 旧主干 | GRU | TCN |
| --- | ---: | ---: | ---: | ---: | ---: |
| AAC192 | −81.99 | −81.70 | −57.24 | −60.37 | −59.02 |
| Vorbis q3 | −77.23 | −77.39 | −61.48 | −66.19 | −66.66 |

因此相对谱误差确有弱分母放大，同时也存在真实的多余能量。
不能仅因分母小而把反例放行，也不能未盲听就断言产生可闻噪声。
TCN 排除这首后的高频谱形均值为 0.6852，原 MatchEdge 为 0.6777；
这只是定位敏感性的诊断，正式结果仍保留该录音。

当前相对 loss 采用全谱能量 1% 的下限，以及能量项的参考功率下限，避免静音梯度发散；
这也减弱了对极弱高频的约束。平均 cutoff 的多分辨率权重和短裁剪评估也可能影响代理与
实际评分的一致性。这里是有证据的优化方向，尚未完成因果消融，不能把全部误差归因于它。
后续应在不损伤真正缺失高频恢复的前提下，加入原生低带宽/近恒等训练对照、
参考感知的多余高频能量约束，以及输入条件化的生成置信度；同时保留低能量场景的有限梯度。
不以统一减弱增强或硬截断高频作为达成恢复目标。

语音结果也有取舍：TCN 高频谱形 0.6792，相对输入 0.7367 有改善，
但弱于 P2 旧主干的 0.6393；能量误差 5.4596 dB，也弱于旧主干 4.6399 dB。
音乐和语音分开报告，不用 56 条语音把 33 条音乐的反例平均掉。
